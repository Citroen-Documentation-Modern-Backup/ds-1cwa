2. Identification
Figure : b2fh00sd
Les transmissions sont identifiées par une étiquette collée sur l’arbre (en "a"), comprenant : Le repère fournisseur.
Liste des fournisseurs :
  • GKN
  • PSA
  • NTN
3. Opérations préliminaires
NOTA : Les couronnes ABS sont supprimées (la fonction réalisée par les couronnes est transférée vers les roulements de roue avant).
Déposer les transmissions.
Maintenir la transmission dans un étau équipé de mordaches.
NOTA : Avant dépose : Repérer la position des soufflets de transmission.
4. Remplacement : Soufflet côté roue
ATTENTION : Remplacer systématiquement les colliers et les circlips déposés.
4.1. Transmissions PSA et NTN
Figure : b2fh002d
Déposer les colliers (1) et (2) ; À l’aide d’une scie à métaux.
NOTA : Repérer la position du soufflet des arbres de transmission ne possédant pas de gorges de position en "a".
Figure : b2fh02qd
Déposer le bol (3) ; À l’aide des outils [0316-A], [4083-T / 0410-A].
Figure : b2fh004d
Déposer :
  • Le jonc d’arrêt (4)
  • Le soufflet de transmission (5)
Reposer :
  • Le soufflet de transmission (5) (neuf)
  • Le jonc d’arrêt (4) (neuf)
Figure : b2fh005d
Poser un collier (6) sur le jonc pour faciliter l’emmanchement du bol (3).
Figure : b2fh02rd
Reposer le bol (3) sur l’arbre ; À l’aide des outils [0316-A], [4083-T / 0410-A].
Déposer le collier (6).
Remplir le soufflet avec toute la graisse disponible dans le kit de réparation.
Reposer le soufflet (5) sur le bol (3).
ATTENTION : Respecter le positionnement du soufflet sur l’arbre, talon du soufflet dans la gorge "a" de l’arbre ou le repère fait au démontage.
Reposer et serrer les colliers (1) et (2) .
4.2. Transmission GKN
NOTA : Le bol de transmission côté roue n’est pas démontable ; Le remplacement d’un soufflet de transmission côté roue nécessite la dépose du soufflet côté boîte de vitesses.
Figure : b2fh00qd
Déposer :
  • Le soufflet de transmission  (côté boîte de vitesses)
  • Les colliers (7), (8)
  • Le soufflet de transmission (9)
Reposer le soufflet de transmission (9) sur la transmission.
Remplir le soufflet avec toute la graisse disponible dans le kit de réparation.
Reposer :
  • Les colliers (7) et (8)
  • Le soufflet de transmission  (côté boîte de vitesses)
5. Remplacement : Soufflet côté boîte de vitesses
ATTENTION : Remplacer systématiquement les colliers et les circlips déposés.
5.1. Transmissions GKN et NTN
Figure : b2fh011d
Déposer les colliers (10), (13).
Écarter le soufflet (11) de transmission .
Déposer verticalement le boîtier tripode (12).
Enlever le maximum de graisse à l’intérieur du soufflet .
Figure : b2fh012d
Nettoyer l’excédent de graisse dans le soufflet et sur le tripode.
Déposer le circlips (14).
Figure : b2fh013d
Déposer le tripode (15) ; À l’aide d’un marteau et d’un chasse-goupille.
Déposer le soufflet (11) de transmission .
Reposer le soufflet de transmission (11) sur la transmission (neuf).
Reposer :
  • Le tripode (15)
  • Le circlips (14)
Remplir le soufflet avec toute la graisse disponible dans le kit de réparation.
Reposer :
  • Le boîtier tripode (12)
  • Les colliers (10) et (13)
5.2. Transmission PSA
NOTA : Côté boîte de vitesses le tripode ne se démontant pas, l’échange du soufflet n’est possible qu’après dépose du joint côté roue.
Figure : b2fh011d
Déposer :
  • Le soufflet de transmission (/)  (côté roue)
  • Les colliers (10), (13)
  • Le boîtier tripode (12)
  • Le soufflet de transmission (11)
Retirer le maximum de graisse du joint de transmission ; Ne pas utiliser de solvant.
Poser le soufflet neuf (11) sur la transmission.
Répartir la graisse entre le soufflet et le tripode.
Reposer :
  • Le boîtier tripode (12)
  • Les colliers (10), (13)
  • Le soufflet de transmission  (côté roue)
6. Colliers de serrage
Figure : b2fh015d
Positionner le soufflet (18) de transmission (Respecter les repères pris lors du démontage).
Reposer les colliers neufs (16) et (17) ; À l’aide de l’outil spécifique (Selon les colliers) :
  • Colliers CLIC ; À l’aide de l’outil [0409]
  • Colliers OETIKER ; À l’aide de l’outil [0412]
Figure : b2fh00bd
Serrer les colliers à oreille ; À l’aide des outils [0413] ou [0409].
Figure : b2fh00cd
Serrer les colliers : Jusqu’au contact "A" = 0 mm.
Figure : b2fh00dd
Après serrage : Vérifier l’espace "B" = 0,5 à 1 mm.
7. Opération complémentaire
Reposer les transmissions.
