C5HG0141P0Dépose - Repose : Motoréducteur volet d’entrée d’air
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Opérations préliminaires
Débrancher la batterie .
2. Dépose
Figure : c5fg011d
Déposer :
  • La garniture (2) sous planche de bord (Côté passager)
  • Le vide-poches (1)
Figure : c5hm060d
Déposer :
  • Les vis (3)
  • Le motoréducteur volet d’entrée d’air (4)
Déconnecter : Le motoréducteur volet d’entrée d’air ( en "a").
NOTA : Climatisation automatique (RFTA) : Récupérer le levier sur le motoréducteur volet d’entrée d’air ; Climatisation manuelle / Chauffage (RF/CH) : Déposer : Le motoréducteur volet d’entrée d’air avec la came.
3. Repose
3.1. Climatisation automatique (RFTA)
Figure : c5hm061d
Indexer le levier (5) sur l’indexage de l’engrenage du volet d’entrée air ( en "b").
3.2. Climatisation manuelle / Chauffage (RF/CH)
Positionner les repères sur le groupe et sur la cinématique l’un en face de l’autre afin d’effectuer le calage du volet d’entrée d’air.
3.3. Opérations communes
Reposer :
  • Le motoréducteur volet d’entrée d’air (4)
  • Les vis (3)
  • Le vide-poches (1)
  • La garniture (2) sous planche de bord (Côté passager)
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
Rebrancher la batterie.
Vérifier le fonctionnement : Motoréducteur volet entrée air.
