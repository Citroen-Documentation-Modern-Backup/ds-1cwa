C5GG013TP0Dépose - Repose : Sièges arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
1.1. Siège arrière gauche
Figure : c5gg03ld
Reculer le siège (arrière gauche) : Le siège arrière (gauche) (4) (Au maximum).
Déposer :
  • Le tapis de coffre
  • La tablette arrière
  • Les vis (1)
Avancer le siège (arrière gauche) (4) (Au maximum).
Déposer :
  • Les vis (2)
  • L’écrou (3)
  • Le siège  (arrière gauche) (4)
1.2. Siège arrière droit
Figure : c5gg03md
Reculer le siège (arrière droit) (7) (Au maximum).
Déposer les vis (5).
Avancer le siège (arrière droit) (7) (Au maximum).
Déposer :
  • Les vis (6)
  • Le siège  (arrière droit) (7)
2. Repose
Procéder dans l’ordre inverse des opérations de dépose.
Serrer les vis de fixation (1), (2), (5), (6) à 2,7 m.daN.
Serrer l’écrou (3) à 2,4 m.daN.
Vérifier le bon fonctionnement électrique des équipements.
