B3FG014GP0Dépose - Repose : Capteur gyromètre / Accéléromètre
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Un outil de diagnostic.
2. Dépose
Couper le contact.
Figure : c5gg02rd
Déclipper le cache de console (1).
Figure : c5gg02sd
Déclipper le cache (2).
Déposer l’écrou (3).
Figure : b3fg09pd
NOTA : Ne pas déposer la console : La dépose de l’écrou (3) permet de bouger la console pour faciliter l’accès aux écrous (4).
Déposer les écrous (4).
Déconnecter le connecteur ( en "a").
Déposer le capteur gyromètre-accéléromètre (5).
3. Repose
ATTENTION : Respecter les couples de serrage .
ATTENTION : Tout capteur gyromètre-accéléromètre (5) ayant subi un choc doit être remplacé.
NOTA : Respecter le sens de montage du capteur gyromètre-accéléromètre (5) : Connecteur vers l’avant du véhicule.
Reconnecter le connecteur  (en "a").
Reposer :
  • Le capteur gyromètre-accéléromètre (5)
  • Les écrous (4)
  • L’écrou (3)
Reclipper :
  • Le cache (2)
  • Le cache-console (1)
À l’aide d’un outil de diagnostic :
  • Effectuer une calibration du capteur gyromètre-accéléromètre (5)
  • Faire une lecture des codes défauts et un effacement si nécessaire
