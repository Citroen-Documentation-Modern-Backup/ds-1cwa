1. Outillage
outil Référence Désignation

 [1503-AY] Manomètre de pression d’huile
Figure : e5ab046t

Figure : e5ab047t

Figure : e5ab048t

2. Dépose
Laisser refroidir le moteur.
Figure : b1fd01zd
Déposer :
  • Les vis (2)
  • L’écran thermique supérieur (1)
Déconnecter le connecteur du capteur de pression d’huile (3) (en "a").
Déposer le capteur de pression d’huile (3).
NOTA : Protéger l’environnement à l’aide d’un chiffon lors de la dépose afin d’absorber l’huile s’écoulant de l’orifice.
3. Contrôle
Figure : b1fd020d
NOTA : Le contrôle de la pression d’huile s’effectue moteur chaud, après vérification du niveau d’huile.
Serrer :
  • L’outil [1503-N] sur le support de filtre à huile
  • L’outil [1503-G] sur l’outil [1503-N]
  • Le capteur de pression d’huile (3) sur l’outil [1503-N]
Reconnecter le connecteur du capteur de pression d’huile (3) (en "a").
Assembler le flexible [1503-B] muni du manomètre [1503-AY] sur l’embout [1503-G].
Relever les valeurs.
Comparer les valeurs relevées sur le manomètre de pression d’huile à celles du tableau .
ATTENTION : Intervenir sur le moteur en cas de valeurs de pression d’huile inférieures à celles du tableau.
4. Repose
IMPERATIF : Respecter les couples de serrage .
NOTA : Protéger l’environnement à l’aide d’un chiffon lors de la dépose afin d’absorber l’huile s’écoulant de l’orifice.
Déconnecter le connecteur du capteur de pression d’huile (3) (en "a").
Déposer :
  • Le manomètre [1503-AY]
  • Le flexible [1503-B]
  • Le capteur de pression d’huile (3)
  • L’embout [1503-G]
  • Le flexible [1503-N]
Reposer le capteur de pression d’huile (3).
Reconnecter le connecteur du capteur de pression d’huile (3) (en "a").
Reposer :
  • L’écran thermique supérieur (1)
  • Les vis (2)
Effectuer le niveau d’huile.
