Figure : b2cp4bjd
1.1. Dépose du capteur de sélection
Déconnecter le connecteur (en "a").
Déposer :
  • Les 2 vis (1)
  • Le capteur de sélection de vitesses (2)
NOTA : Lors de la dépose, on entend la détente du ressort situé dans le capteur .
1.2. Dépose du capteur de passage
Déconnecter le connecteur (en "b").
Déposer :
  • Les 2 vis (4)
  • Le capteur de passage (3)
NOTA : Lors de la dépose, on entend la détente du ressort situé dans le capteur .
2. Repose
ATTENTION : Le non respect du positionnement des doigts des capteurs entraîne une défaillance du système.
2.1. Repose capteur de sélection
Figure : b2cp4bkd
Tourner le doigt d’armement (5) jusqu’en butée dans le sens horaire. (suivant flèche).
Figure : b2cp4bld
Positionner le capteur de sélection (2) sur le doigt d’armement (5).
NOTA : Le capteur de sélection est décalé de 90° par rapport à sa position initiale (figure A).
Faire pivoter le capteur de sélection de 90° dans le sens horaire (suivant flèche) pour armer le ressort du capteur.
NOTA : Le capteur de sélection est dans sa position initiale (figure B).
Reposer les 2 vis (1).
2.2. Repose capteur de passage
Figure : b2cg2wgd
Tourner le doigt d’armement (6) jusqu’en butée dans le sens horaire.
Positionner le capteur de passage (3) sur le doigt d’armement (6).
NOTA : Le capteur de passage est décalé de 90° par rapport à sa position initiale (figure C).
Faire pivoter le capteur de passage de 90° dans le sens horaire (suivant flèche) pour armer le ressort du capteur.
NOTA : Le capteur de passage est dans sa position initiale (figure D).
Reposer les 2 vis (4).
2.3. Repose (suite)
Figure : b2cp4bnd
E = Montage correct.
F = Montage incorrect.
ATTENTION : Ne pas intervertir les connecteurs entre les 2 capteurs .
Connecter les connecteurs en "a" et "b" (figure E).
NOTA : Si les connecteurs sont inversés, le moteur ne peut pas démarrer (figure F).
