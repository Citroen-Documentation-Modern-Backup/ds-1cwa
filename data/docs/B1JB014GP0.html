B1JB014GP0Mémento technique : Additifs pour filtre à particules
Ce document décrit les opérations d’entretien en après-vente suites aux évolutions des additifs filtre à particules.
ATTENTION : Ce document concerne uniquement le remplissage de réservoir rigide. L’additif doit être utilisé uniquement sur les véhicules équipés d’un filtre à particules.
1. Nouveaux additifs filtre à particules de 3ème génération
Fournisseurs et dénomination :
  • RHODIA : EOLYS POWERFLEX
  • INFINEUM : F7995
2. Ancien type d’additif
L’additif DPX 42 est toujours disponible et doit être utilisé pour toute intervention sur des véhicules ayant du DPX 42.
L’additif EOLYS 176 est remplacé par l’additif INFINEUM F7995. À épuisement des stocks c’est le nouveau produit qui sera fourni.
3. Compatibilité entre additifs
L’additif DPX42 n’est miscible avec aucun autre additif.
Les deux additifs EOLYS POWERFLEX et INFINEUM F7995 ne sont pas miscibles entre eux.
NOTA : Les différentes générations d’additifs n’ont pas d’impact sur les calibrations du calculateur contrôle moteur.
ATTENTION : Il est interdit de mélanger les additifs INFINEUM F7995 et Rhodia EOLYS POWERFLEX entre eux.
4. Opérations de remplIssage ou d’appoint d’additif
Table de correspondances pour les interventions de remplissage ou d’appoint
Additif présent sur le véhicule Couleur de l’encliquetable de l’interface de remplissage Additif à utiliser pour toutes interventions
DPX 42 Encliquetable ni bleu ni vert DPX 42
EOLYS 176 Encliquetable vert EOLYS 176 - INFINEUM F7995
INFINEUM F7995 Encliquetable vert INFINEUM F7995
EOLYS POWERFLEX Encliquetable bleu EOLYS POWERFLEX
