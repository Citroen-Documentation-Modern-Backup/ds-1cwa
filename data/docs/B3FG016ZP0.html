B3FG016ZP0Dépose - repose : Étrier de frein avant
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Remplacement systématique de pièces
Désignation Quantité (Pour un côté)
Vis (Étrier de frein avant ) 2
Vis (Support d’étrier de frein avant) 2
2. Outillage
Matériel :
  • 1 Pince de type FACOM D.60A
  • Un presse-pédale
3. Dépose
Lever et caler le véhicule, roues avant pendantes.
Placer le presse-pédale sur la pédale de frein, afin d’éviter l’écoulement du liquide de frein lors du désaccouplement des tubes de frein.
Déposer :
  • Les roues avant
  • Le flexible de frein
Obturer le raccord et l’étrier de frein ; À l’aide de bouchons de propreté.
Figure : b3fg2gcd
Déposer :
  • Les vis (1)
  • L’étrier de frein (2)
Repousser les pistons ; À l’aide d’une pince (Type FACOM D.60A) (Intercaler une cale entre l’outil et la plaquette pour repousser les pistons à fond dans leurs logements).
Figure : b3fg0i8d
Déposer :
  • Les plaquettes de frein (5)
  • Les cales d’appui (3), (4) des plaquettes de frein (5)
Figure : b3fg0i9d
Déposer :
  • Les vis (6)
  • Le support d’étrier de frein (7)
4. Nettoyage
NOTA : Ne pas utiliser d’air comprimé pour nettoyer les freins.
4.1. 1ère possibilité
Nettoyer le disque de frein et l’étrier de frein à l’aide d’un produit nettoyant frein recommandé.
Laisser sécher et égoutter.
Essuyer à l’aide d’un chiffon papier.
4.2. 2ème possibilité
Utiliser un appareil de dépoussiérage homologué par le constructeur .
5. Contrôle
Contrôler visuellement :
  • L’étanchéité autour du piston
  • Le bon état et l’ajustement parfait des soufflets de protection
  • L’usure des disques de frein
Remplacer les pièces défectueuses.
ATTENTION : Aucune trace de graisse, d’huile, de lubrifiant n’est tolérée sur les garnitures des plaquettes de frein.
6. Repose
ATTENTION : Respecter les couples de serrage.
Couples de serrage :
  • Système de freinage
  • Roues
ATTENTION : Nettoyer systématiquement le taraudage des vis (6) dans les pivots à l’aide d’un taraud, sur toute la longueur du taraudage.
Reposer :
  • Le support d’étrier de frein (7)
  • Les vis neuves préenduites (6)
  • Les cales d’appui (3), (4) des plaquettes de frein (5)
Reposer :
  • Les plaquettes de frein (5)
  • L’étrier de frein (2)
  • Les vis neuves préenduites (1)
  • Le flexible de frein
Remplir et purger le circuit de freinage .
Reposer :
  • Les roues avant
  • Le véhicule sur ses roues
IMPERATIF : Donner plusieurs coups de frein, moteur en marche, avant de faire rouler le véhicule.
Vérifier le fonctionnement des freins.
Contrôler le niveau de liquide de frein et le compléter si nécessaire.
