B2CGDXP0Dépose - repose : Moteur électrique de groupe électropompe
BVM MC ET BVM PILOTEE 6 RAPPORTS
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Matériel : Un outil de diagnostic.
2. Opérations préliminaires
Effectuer une mise hors pression du circuit hydraulique ; À l’aide de l’outil de diagnostic.
Déposer :
  • L’actionneur de pilotage
  • Le groupe électropompe d’actionneur
3. Dépose
Figure : c5dp07cd
Déposer :
  • Les 2 vis (1)
  • Le réservoir hydraulique (2)
Figure : c5dp07dd
Déposer :
  • Les 3 vis (3)
  • Le moteur électrique
4. Repose
Figure : c5dp07ed
Vérifier l’absence de corps étrangers dans le logement du moteur électrique.
Reposer l’entraîneur (4) sur le doigt d’entraînement de la pompe (5).
Figure : c5dp07fd
Aligner le méplat de l’entraîneur (4) avec les deux taraudages "a" ; À l’aide d’un tournevis.
Nettoyer parfaitement les surfaces.
Figure : b2cg19wd
Tourner l’entraîneur du moteur (6) afin d’aligner le méplat avec les deux perçages "b".
Nettoyer parfaitement les surfaces.
Reposer le moteur électrique.
Figure : c5dp07hd
"A" : Montage incorrect.
"B" : Montage correct.
ATTENTION : Le moteur doit être bien plaqué sur la pompe (Montage "B").
S’il y a un jeu "C" entre les deux faces d’appui, l’entraîneur du moteur (6) n’est pas emboîté dans l’entraîneur (4).
Dans ce cas, déposer le moteur et refaire les alignements décrits plus haut.
Reposer les 3 vis (3).
Figure : c5dp07cd
Reposer le réservoir hydraulique (2).
Serrer les vis (1) à 1 m.daN.

  • Le groupe électropompe d’actionneur
  • L’actionneur de pilotage
Effectuer la remise en pression et la purge du circuit hydraulique ; À l’aide de l’outil de diagnostic.
