1. Outillage
Figure : e5ap30wd
[1] Outils de dégarnissage (-).1350.
2. Opération préliminaire
Déposer le capot moteur .
3. Déshabillage
3.1. Insonorisant / Butée de capot
Figure : c4as01jd
Déposer : Les butées (1) ; À l’aide de l’outil [1].
Déclipper : Les agrafes ( en "b").
Déposer : L’insonorisant de capot moteur (2).
Déclipper : Les agrafes ( en "a").
Déposer : Les insonorisants du capot moteur (3).
3.2. Gicleurs de lave-vitre
Figure : c4as01kd
Déclipper les gicleurs de lave-vitre (4) (suivant flèche ) ; À l’aide de l’outil [1].
Désaccoupler les tuyaux ( en "c") (Opération symétrique).
Déclipper les tuyaux ( en "d").
Déposer : Les durits de gicleurs lave-vitre.
4. Habillage
4.1. Insonorisant de capot moteur
Reposer : Les insonorisants du capot moteur (3).
Clipper : Les agrafes ( en "a").
Reposer : L’insonorisant de capot moteur (2).
Clipper : Les agrafes ( en "b").
Reposer : Les butées (1) ; À l’aide de l’outil [1].
4.2. Gicleurs de lave-vitre
IMPERATIF : Prévoir le remplacement des agrafes .
Reposer : Les durits de gicleurs lave-vitre (5).
Clipper les tuyaux ( en "d").
Accoupler les tuyaux ( en "c") (Opération symétrique).
Clipper : Les gicleurs de lave-vitre (4) (suivant flèche ) ; À l’aide de l’outil [1].
5. Opération complémentaire
Reposer le capot moteur .
