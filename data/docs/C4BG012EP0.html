C4BG012EP0Dépose - Repose : Volet arrière
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Outillage
Figure : e5ap30wd
[1] Palettes de dégrafage (-).1350.
2. Opérations préliminaires
Ouvrir le volet arrière .
Débrancher la batterie .
3. Dépose
Figure : c4bg058d
Déposer :
  • La tablette arrière (1)
  • Le faux plancher (2)
Figure : c4bg059d
Déchausser le joint de coffre  (partiellement).
Déposer :
  • Le tapis de coffre (5)
  • Les 2 pions de fixations (3)
  • Les 2 vis (4)
  • La garniture de seuil de coffre (6)
Figure : c4bg05ad
Rabattre le ou les dossiers de siège arrière.
Déchausser le joint de porte : Arrière gauche (partiellement).
Déposer (Côté gauche ) :
  • La garniture de coffre (8)
  • La garniture de custode (7)
Figure : c4bg05bd
Déposer la vis de masse (10).
Déconnecter le connecteur ( en "b").
Dégrafer le faisceau ( en "a") ; À l’aide de l’outil [1].
Écarter : Le faisceau de volet arrière (9).
Figure : c4bg05cd
Déclipper le 3ème feu stop (11) (suivant flèche ) ; À l’aide de l’outil [1].
Déconnecter : Le connecteur du 3ème feu stop .
Débrancher le tube de lave-vitre ( en "c").
Déposer le 3ème feu stop (11).
Figure : c4bg05dd
NOTA : Pour la suite des opérations, deux opérateurs sont nécessaires.
Déposer les vis (12).
Désaccoupler : Les vérins de volet ( en "d") ; À l’aide d’un petit tournevis.
Déposer le volet arrière (13).
4. Repose
Reposer :
  • Le volet arrière (13)
  • Les vis (12) ; Effectuer un préserrage à 0,6 m.daN
  • Les vérins de volet
Reposer : La vis de masse (10).
Reconnecter le connecteur ( en "b").
Agrafer le faisceau ( en "a").
Rebrancher la batterie.
5. Réglage
Fermer le volet arrière .
Régler jeux et affleurements ; À l’aide des vis (12).
Si nécessaire : Le réglage du volet peut être complété par le réglage de la gâche du volet arrière .
Ouvrir le volet arrière .
Serrer les écrous (12) à 1,5 m.daN.
Procéder dans l’ordre inverse des opérations de dépose.
Vérifier le fonctionnement des équipements.
