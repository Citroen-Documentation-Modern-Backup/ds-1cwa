D1BG010VP0Dépose - Repose : Démarreur
IMPERATIF : Respecter les consignes de sécurité et de propreté .
1. Dépose
IMPERATIF : Laisser refroidir la ligne d’échappement ; Avant toute intervention sur le démarreur.
Mettre le véhicule sur un pont élévateur.
Débrancher la batterie .
Figure : d1bm01nd
Déposer :
  • Le déflecteur d’air (4)
  • Le raccord d’entrée d’air (5)
  • La vis (1)
  • Le résonateur d’air (2)
  • Le cache batterie (3)
  • La batterie
  • Le bac à batterie
Figure : d1bm00bd
Déconnecter le connecteur  (en "a").
Déposer :
  • L’écrou (8)
  • Les vis (7)
  • Le collier du flexible d’échappement ; Écarter
  • La ligne d’échappement
  • Le démarreur (9) (Sortir le démarreur par le dessous de la boîte de vitesses)
2. Repose
ATTENTION : Vérifier la présence de la goupille de centrage .
Reposer :
  • Le démarreur (9)
  • Les vis (7) ; Serrer à 2 m.daN
  • L’écrou (8) ; Serrer à 1,6 m.daN
Connecter le connecteur  (en "a").
Reposer :
  • La ligne d’échappement
  • Le collier du flexible d’échappement
  • Le bac à batterie
  • La batterie
  • Le cache batterie (3)
  • Le raccord d’entrée d’air (5)
  • Le résonateur d’air (2)
  • La vis (1)
  • Le déflecteur d’air (4)
Rebrancher la batterie.
ATTENTION : Réaliser les opérations à effectuer après un rebranchement de la batterie.
