B1HD0147P0Contrôle : Pression d’alimentation GPL
IMPERATIF : Respecter les consignes de sécurité et de propreté .
IMPERATIF : Toute intervention sur un véhicule fonctionnant avec du gaz doit s’effectuer dans un local aéré.
1. Contrôle
NOTA : Effectuer le contrôle à l’aide d’un outil de diagnostic.
Démarrer le moteur.
Placer le commutateur gaz/essence sur le mode gaz.
Attendre le basculement en mode gaz.
NOTA : Le voyant du commutateur gaz/essence doit être vert.
Brancher l’outil de diagnostic :
  • Sélectionner le menu LANDIRENZO
  • Sélectionner le menu : Test des actionneurs
Contrôler la valeur de pression d’alimentation GPL :
  • Si la valeur de la pression d’alimentation GPL est de 500 mbars : Le véhicule est conforme
  • Si la valeur de pression d’alimentation GPL est différente : Régler la valeur de pression d’alimentation
2. Réglage
Lever et caler le véhicule sur un pont à 2 colonnes.
Déposer :
  • Les roues avant
  • Les pare-boue avant
  • Le pare-chocs avant
  • Le projecteur avant gauche
Figure : b1hdzhfd
Régler (en "a") ; À l’aide d’une clé 6 pans creux de 4 mm :
  • Tourner la vis de réglage dans le sens horaire pour diminuer la valeur
  • Tourner la vis de réglage dans le sens antihoraire pour augmenter la valeur
Débrancher l’outil de diagnostic.
Démarrer le moteur.
Vérifier le bon fonctionnement du mode GPL.
Reposer :
  • Le projecteur avant gauche
  • Le pare-chocs avant
  • Les pare-boue avant
  • Les roues avant
  • Le véhicule sur ses roues
